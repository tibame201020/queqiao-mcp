## CLI/runtime compatibility closure

Queqiao 0.8.1 makes role setup an interactive TUI flow and uses named selectors such as `--worker` / `--gateway`, explicit `--json` for machine-readable output, and self-contained Worker enrollment join codes.

The release acceptance harness was updated so it does not automate the interactive setup TUI. Instead, an isolated test-only bootstrap invokes the Queqiao 0.8.1 setup primitives against a temporary runtime root. The actual lifecycle and enrollment path continues through the released Queqiao CLI/runtime surface.

The acceptance harness uses:

- temporary `LOCALAPPDATA`
- dynamic loopback ports
- temporary Extension Hub state
- temporary npm registry
- temporary Workspace
- temporary Chrome profile/runtime

Existing Stable and Shadow runtime configuration is not modified.
